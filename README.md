# Sarex Studio Cinematics (Fabric 1.21.1)

Un solo mod (codigo + video + audio), requiere Fabric API.

    /sarexstudio escena <nombre> [jugadores]
    /sarexstudio detener [jugadores]
    /sarexstudio lista

Escenas: eon_y_su_padre, guardian, phora_ruleta, reviil_caida, dialogo_jefe, ruleta_final

Instalar: poner sarexstudio-cinematics-1.0.0.jar y Fabric API en mods/ (servidor y jugadores;
en mundo de un jugador activa los trucos). Se compila solo con GitHub Actions (ver workflow).
Las cinematicas originales son de Eufonia Studio (DedSafio 4): pedir permiso y dar credito.
